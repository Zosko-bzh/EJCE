# Dossier SQL
Déposez ici les fichiers de base de données SQL pour le projet EJCE.

Ce dossier est prêt et correspond à la demande. Vous pouvez y déposer vos scripts `.sql`.
Pour l'importer dans la base MySQL (via Docker par exemple), vous pourriez ajouter un volume dans le docker-compose ou importer manuellement depuis PDO dans Symfony ou le CLI MySQL.
